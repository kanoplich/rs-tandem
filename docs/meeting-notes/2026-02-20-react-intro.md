# Meeting Notes #3 - React Intro, CI/CD and Deploy

**Дата:** 20 февраля 2026

**Длительность:** ~2 часа

### Цель встречи

Изучить основы работы с React, настроить процессы непрерывной интеграции и деплоя приложения.

### Выполненные задачи

1. Рассмотрели настройку GitHub Actions - линтинг, проверка типов, сборка проекта и прогон тестов при создании PR и пушах в develop.
2. Настроили автоматический деплой на Netlify при мерже в основную ветку.
3. Познакомились с базовыми концепциями React: компонентный подход, хуки (useState, useEffect), пропсы и состояние. Разобрали примеры.

## Принятые решения

1. Добавить настройки CI/CD в проект.
2. Использовать функциональные компоненты с хуками, избегать классовых компонентов.
3. Более подробно самостоятельно рассмотреть документацию React для дальнейшей работы по проекту.
