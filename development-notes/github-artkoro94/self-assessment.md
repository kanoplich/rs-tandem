## 2. Описание работы

### Роль и зона ответственности

В рамках проекта я выступал в роли **Frontend-разработчика**. Моя зона ответственности включала разработку функционала авторизации (Login Page) и экрана истории пользователя (History Page). Я отвечал за корректную работу пользовательских сценариев — ввод данных, состояние загрузки, ошибок и пустых данных. Также я реализовал взаимодействие UI с backend через API Service Layer, обеспечил доступность интерфейса (accessibility), адаптивность под мобильные устройства и покрытие критической логики unit-тестами.

### Инструменты и технологии

- **Стек фронтенда:** React, TypeScript, Tailwind CSS, shadcn/ui.
- **Инфраструктура:** Husky, ESLint, Prettier, Git
- **Работа с формами:** React Hook Form (управление состоянием форм), Zod (схемы валидации и типизация).
- **Архитектура:** Feature-Sliced Design (FSD) — разделение логики на слои shared, features и pages.
- **Тестирование:** Vitest (написание тестов для проверки логики форм).
- **Дополнительно:** Lucide-react (иконки), Sonner (уведомления/тосты).

### Что было сделано

- **Реализована страница входа (Login Page):** Создал форму авторизации с использованием `React Hook Form` + `Zod`. Реализовал валидацию email и пароля, обработку ошибок, а также корректное отображение сообщений при неуспешной авторизации.

- **Реализована History Page:** Экран с отображением пользовательских данных и обработкой состояний.

- **Интеграция с API:** Реализовал взаимодействие с backend через API Service Layer. UI-компоненты не выполняют прямые `fetch`-запросы, а используют сервисы, что позволило изолировать логику работы с данными и упростить поддержку.

- **Архитектурные решения (FSD):** Структурировал код по слоям (`features`, `shared`). Логику вынес в отдельный слой, UI оставил максимально "чистым". Это позволило избежать дублирования и упростить масштабирование.

- **Accessibility (a11y):** Добавил базовую доступность форм: работу с клавиатурой и понятные ошибки.

- **UI/UX и адаптивность:** Сверстал интерфейсы с использованием `shadcn/ui` и Tailwind CSS. Обеспечил корректное отображение на мобильных устройствах (от 320px), включая формы и layout.

- **Тестирование:** Написал unit-тесты для login формы (5 сценариев).

- **Работа с качеством кода:** Соблюдал строгую типизацию (TypeScript strict, без any), участвовал в code review и следил за соответствием архитектурным принципам проекта.
