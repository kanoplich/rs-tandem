Я добавил стриминг ответа LLM. Теперь при вызове Edge Function мы получаем стрим, и фидбек от LLM сразу же показывается на фронте. В данной работе я решил множество проблем, с которыми пришлось столкнуться. Во-первых, я переделал функцию, которые вызывают Edge Function, чтобы иметь возможность обрабатывать стрим. Также нужно было придумать способ отделять фидбек от JSON объекта с данными по ответу, чтобы он не показывался пользователю. Для этого пришлось использовать буфер, который ищет определенную фразу, с которой начинается JSON объект с данными.

Поэтому я переписал код с одним запросом и сложным парсингом на код с двумя запросами и отдельными ответами. Код был проще и надежнее, но этот вариант оказался менее подходящим, поскольку в результате мы получали два разных фидбека от двух запросов — один пказывался пользователю, а второй сохранялся в таблицах, и они могли отличаться.
