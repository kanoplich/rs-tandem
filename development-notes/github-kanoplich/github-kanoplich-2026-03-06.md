Сегодня работал с Supabase и Docker'ом.

Поля covered и missed в таблице submissions изначально были JSONB, но хранили просто плоский список строк. Переделал на TEXT[] — типизированный массив PostgreSQL. Причина: JSONB не валидирует содержимое (можно записать число или объект вместо строки), а Supabase генерирует для него тип Json (unknown в TypeScript) — теряется типобезопасность. TEXT[] гарантирует что каждый элемент — строка, и на уровне БД, и в сгенерированных типах (string[]).

Добавил тестовые данное в базу локально и на удаленный репозиторий через SQL editor. А в seeds решили данные не добавлять, чтобы не светить на Гитхабе. Теперь все таблицы заполнены, можно заниматься разработкой. Данные предоставила ментор Ольга.

Так же добавил в README.md инструкцию для команды, как развернуть базу локально. Всё протестировал, всё работает.
