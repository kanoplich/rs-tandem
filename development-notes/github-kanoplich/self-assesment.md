## 2. Описание работы

### Роль и зона ответственности

В рамках командного проекта я выступал в роли Fullstack-разработчика с фокусом на бэкенд-логику, интеграцию с базой данных и разработку ключевого пользовательского интерфейса. Основные направления моей работы: настройка инфраструктуры проекта, интеграция с Supabase, разработка бэкенд-логики и создание страницы тренировки интервью с интеграцией AI. Кроме того, на первой неделе разработки я исполнял роль Тимлида — мы с командой решили, что эта роль будет переходящей, чтобы каждый участник мог попробовать себя в управлении и координации.

### Инструменты и технологии

- **Стек фронтенда:** React, TypeScript, Tailwind CSS, shadcn/ui
- **Бэкенд и BaaS:** Supabase (Auth, Database, RPC, Row Level Security)
- **Инфраструктура:** Docker, Git (GitHub Flow), Husky, ESLint, Prettier
- **AI интеграция:** Streaming ответов, работа с ReadableStream и TextDecoder
- **Архитектура:** Feature-Sliced Design (FSD)

### Что было сделано

1. **Инициализация и настройка проекта**  
   Настроил репозиторий GitHub, защиту веток, PR-шаблоны. Настроил GitHub Actions для автоматического запуска тестов и линтера при создании pull request'ов. Инициализировал проект, установил роутинг, формы, Supabase. Настроил ESLint, Prettier, TypeScript, Husky. Добавил UI библиотеку shadcn/ui. Всё это развернул на Netlify с настроенным автоматическим деплоем при пуше в ветку develop.

2. **Интеграция Supabase и бэкенд-логика**  
   Создал и настроил проект в Supabase, разработал таблицы, RLS политики и RPC-функции. Настроил триггер для автоматического добавления данных в таблицу profiles при регистрации пользователя. Написал функции для регистрации, логина, логаута и отслеживания состояния авторизации.
   Реализовал моковые данные и методы для таблиц Topic, Task, Submissions. Написал функции-мэпперы для преобразования данных, получаемых от Supabase. Разработал RPC функции для получения UserStats и TopicProgress. Добавил функцию getSubmissionHistory для получения истории ответов пользователя.

3. **Работа с Docker и локальной БД**
   Развернул локальную среду Supabase через Supabase CLI (который запускает контейнеры PostgreSQL, Studio, API и Edge Functions через Docker). Это позволило разрабатывать и тестировать миграции локально, а также работать с полноценной копией базы данных.

4. **Настройка OAuth аутентификации**
   Настроил OAuth для Google и GitHub. Создал два проекта для локальной и глобальной разработки (из-за ограничения GitHub на callback адреса). Настроил env переменные и config.toml.

5. **Разработка страницы тренировки интервью**
   Сверстал страницу, работал с shadcn/ui и Tailwind CSS. Реализовал приветственное сообщение, отображение текущего вопроса, поле для ввода с поддержкой форматирования кода, блокировку поля после отправки.
   Написал кастомный хук useTasksLoading — загрузка задач с поддержкой режимов restart/continue и useTaskSession, управляющий состоянием: текущая задача, ответ пользователя, фидбэк, результаты. Реализовал посимвольный вывод ответа от AI (streaming). Написал компонент TaskResult с отображением score, coveredPoints, missedPoints. Добавил кнопки перехода к следующему вопросу (при score ≥ 70) и "Попробовать снова". Реализовал прогресс-бар и кнопку завершения тренировки.

6. **AI интеграция и Judge**
   Настроил взаимодействие с Judge (AI оценщик). Реализовал streaming ответов через ReadableStream и TextDecoder для посимвольного вывода фидбэка пользователю.

7. **Тестирование и Code Review**
   Писал unit-тесты для методов Supabase. Проводил code review пул-реквестов команды. Записал видео-презентацию модуля аутентификации.

## 2 личных Feature Component

**1. Полноценная интеграция Supabase (BaaS слой)**

- Настройка проекта Supabase (таблицы, RLS политики, RPC функции)
- Функции авторизации: регистрация, логин, логаут, onAuthStateChange
- OAuth интеграция (Google, GitHub) с двумя проектами (локальный/продакшн)
- Триггер на добавление данных в таблицу profiles
- Методы для работы с таблицами (Topic, Task, Submissions)
- RPC функции для Dashboard (UserStats, TopicProgress)
- Функции-мэпперы для преобразования данных, получаемых от Supabase
- Работа с Docker для локальной БД

**2. Страница тренировки интервью**

- Верстка страницы (Tailwind CSS, shadcn/ui)
- Кастомный хук useTasksLoading (загрузка задач с поддержкой режимов start/continue, фильтрация уже пройденных задач)
- Кастомный хук useTaskSession (управление сессией, задачами, ответами, фидбэком)
- Отображение score, covered, missed, навигация
- Streaming ответов от AI через ReadableStream + TextDecoder
- Прогресс-бар выполнения задач
- Бизнес-логика: переход при score ≥ 70%
- Обработка ошибок (Judge недоступен, нет авторизации)
