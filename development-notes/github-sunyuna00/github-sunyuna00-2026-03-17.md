**Что было сделано:**

Сегодня работала над глобальным компонентом ErrorBoundary для приложения. Он обернул весь App, поэтому теперь любые ошибки в приложении будут перехватываться и вместо сломанного интерфейса пользователю показывается понятное сообщение.

Создала отдельный компонент ErrorBoundary, где хранится информация об ошибке и есть кнопка для перезагрузки страницы. Все текстовые сообщения вынесла в константы

Сделала адаптивную верстку: иконка ошибки, заголовок, поясняющий текст, блок с сообщением от сервера и кнопка “Обновить страницу” с иконкой. Особое внимание уделила тому, чтобы ошибки сервера визуально отличались от остальных сообщений.
