**Что было сделано:**

Вчера реализовала компонент ProfileHeader для страницы профиля.

Компонент отображает имя пользователя, email, аватар (если есть) или инициалы (initials) в качестве заглушки, а также бейджи этапов с активным/неактивным состоянием.
Для получения данных пользователя создала отдельный кастомный хук useUserProfile.

Вёрстка адаптивная
