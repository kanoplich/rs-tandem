# Дата: 2026-03-14

## Code Review

- [PR #114: Development of Stagetabs](https://github.com/kanoplich/rs-tandem/pull/114) — 3 комментария

1. Предложила улучшить структуру текстов этапов. Сейчас используются три отдельных объекта (`STAGE_FIRST_TEXT`, `STAGE_SECOND_TEXT`, `STAGE_THIRD_TEXT`), из-за этого появляется дублирование. Предложила объединить их в массив и рендерить через `map`, чтобы код было проще масштабировать. Также привела пример и указала, что похожее использование есть в `landing/ui/why-choose-us`.

2. Обратила внимание на названия этапов (`Stage 1`, `Stage 2`, `Stage 3`). Предложила обсудить с менторами перевод на русский (`Этап 1`, `Этап 2`, `Этап 3`), так как в будущем планируется переключение языка. Также предложила вынести эти значения в `shared/model`, потому что они используются на нескольких страницах.

3. Нашла небольшую проблему в `Tabs`: `defaultValue="stages1"` не совпадает со значениями `TabsTrigger` (`stage1`, `stage2`, `stage3`). Из-за этого первая вкладка может не быть активной по умолчанию. Предложила заменить на `defaultValue="stage1"`.

- [PR #112: Кнопки логина Google Github](https://github.com/kanoplich/rs-tandem/pull/112) — 3 комментария

1. Обратила внимание, что кнопки OAuth имеют фиксированную ширину (`w-48`). На мобильных экранах из-за этого они могут выглядеть слишком большими и не помещаться в контейнер. Предложила сделать их адаптивными через `flex` или `grid`

2. Также заметила, что при клике сразу вызывается асинхронная функция `manageSignIn`. Если авторизация проходит долго, пользователь может нажать кнопку несколько раз подряд. Предложила временно блокировать кнопку во время запроса.

3. Предложила добавить состояние загрузки (`loading`), чтобы во время авторизации кнопка становилась `disabled`. Привела пример с `useState`, где состояние включается перед запросом и сбрасывается после завершения.
