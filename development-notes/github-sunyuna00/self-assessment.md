## 2. Описание работы

### Роль

В рамках проекта я выступала как Frontend разработчик.

---

### Инструменты и технологии

- **Стек фронтенда:** React, TypeScript, Tailwind CSS, Lucide React, shadcn/ui
- **Инструменты разработки:** ESLint, Prettier, Git (GitHub Flow)
- **Архитектура:** Feature-Sliced Design (FSD)

---

### Что было сделано

1. **Landing Page Components**  
   Сделала компоненты лендинга: Training, WhyChooseUs, HowItWorks, ReadyToStart.  
   Настроила адаптивную сетку, плавные анимации появления элементов, кнопки и ссылки с навигацией через `Button` + `Link`.

2. **Страница профиля пользователя**  
   Создала страницу профиля, где отображается имя, email, аватар и прогресс пользователя.  
   Добавила визуальное отображение статистики и прогресса по этапам. Страница адаптивная и удобная для мобильных и десктопов.

3. **Error Boundary**  
   Реализован глобальный компонент для обработки ошибок в приложении, чтобы приложение не падало и отображало пользовательское сообщение об ошибке.

4. **Footer**  
   Создан компонент Footer с навигацией, ссылкой на RS School и ссылками на GitHub-аккаунты разработчиков.

5. **Адаптивность и доступность**  
   Все компоненты адаптированы под мобильные устройства, предусмотрены aria-labels для кнопок и ссылок.

6. **Header с мобильным меню**
   Создала Header с навигацией и мобильным меню, которое открывается и закрывается

## 2 личных Feature Component

**1. Landing Page с интерактивными секциями**

- Основной лендинг, где пользователь знакомится с приложением и его возможностями.
- В секции Training рассказывается, что приложение помогает готовиться к техническим собеседованиям RS School с интерактивными тренировками и персональной обратной связью.
- Раздел WhyChooseUs показывает, что AI-интервьюер не подсказывает ответы, а заставляет думать. Там описано, сколько полезных заданий и подсказок доступно.
- HowItWorks объясняет простой процесс подготовки, ReadyToStart мотивирует присоединяться к тысячам студентов.
- Все компоненты адаптивные для мобильных и десктопов, есть плавные анимации появления элементов и интерактивные карточки.

**2. Профиль пользователя с прогрессом и достижениями**

- Страница профиля отображает имя, email, аватар и прогресс пользователя по этапам обучения с процентами.
- Есть визуальная статистика и прогресс, показывается выполнение каждого этапа.
- Пользователь может отслеживать свои достижения и успехи в приложении.
- Страница адаптивная, с поддержкой мобильных экранов.
