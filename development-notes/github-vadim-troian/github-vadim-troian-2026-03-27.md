# Дата: 2026-03-27

- **Что было сделано:**

Начата работа по имплементации **Theme Switcher:** переключение тем (Light/Dark) через Context. Поскольку макет нашего проекта был заточен под одну тему - темную, то и в файле глобальных стилей была небольшая путаница: и в `:root` и в блоке `.dark` были прописаны цвета для темной темы поэтому в первую очередь были перенесены все «темные» значения из `:root` в блок `.dark`, а в `:root` прописаны стили для светлой темы. Теперь по умолчанию (`:root`) всё светлое, а когда надо будет переключится на `.dark` то значения переменных перезапишутся на темные. При этом желтый акцентный цвет primary остался таким же и в темной и в светлой теме.

- **Проблемы:**

Поскольку в нескольких местах в разметке применяли классы `text-white` то в светлой теме не были видны некоторые элементы навигации

- **Решение:**

Поиском прошелся по всему проекту и заменил везде где встречается `text-white`, на `text-light` - теперь в светлой теме просматриваются элементы, которые ранее не были видны.
