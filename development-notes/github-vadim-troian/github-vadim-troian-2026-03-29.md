# Дата: 2026-03-29

- **Что было сделано:**

Завершена работа по имплементации **Theme Switcher:** переключение тем (Light/Dark) через Context.

**Dark-тема** приоритетна при первом заходе. После при помощи кнопки-переключателя (ThemeToggle) в Header в виде иконки солнца/луны - пользователь переключается между светлой и темной темами. Выбор пользователя сохраняется в localStorage.

Т.е. используется **`useState` (ленивая инициализация)**: Функция внутри `useState` выполняется только один раз при первом рендере. Она проверяет `localStorage`. Если пользователь уже заходил и выбрал светлую тему, она применится. Если нет — возьмется `defaultTheme` (в нашем случае — Dark). Т.о. мы проверяем `localStorage`, чтобы при перезагрузке страницы тема не "слетала". Приложение помнит тему даже после закрытия браузера, а при очищении вручную localStorage - показывает Dark-тему.

Цвета меняются через манипуляцию классом на теге `<html>`. Вся стилизация завязана на наличии или отсутствии класса `.dark`.

Поскольку некотрые элементы были плохо видны в светлой теме - подкрутил цвета в глобальном файле стилей.

- **Проблемы:**

Не видны были SVG-иконки RS School и Github в светлой теме.

- **Решение:**

Отредактировал SVG-иконку RS School, путем замены в ней `fill="white"` на `fill="currentColor"`, теперь класс `fill-current` позволяет управлять цветом иконки через обычный `text-color`. Такую же замену сделал для компонента GithubIcon: `<GithubIcon className="w-5 h-5 text-light fill-current" />`
