- **Проблемы:**

При вынесении объекта `registerDefaultValues` в отдельную константу TypeScript выдал ошибку, так как структура объекта оказалась - неполная. Т.е. по умолчанию в Zod все поля **обязательны**, если явно не указано `.optional()`. Поэтому TypeScript ожидает, что в объекте `registerDefaultValues` имя будет присутствовать.

- **Решение:**

Так как для инициализации формы (особенно поскольку мы используем _React Hook Form_ ) лучше явно задать пустые строки для всех полей, чтобы избежать проблем с «неуправляемыми» (uncontrolled) инпутами, а регистрация невозможна без имени, то в объект было добавлено дефолтное значение : ` firstName: '',`

В ходе изучения проблемы узнал, что `.refine` (проверка совпадения паролей) работает только **после** того, как все базовые поля (включая `firstName`) прошли первичную проверку на тип. Если мы не передадим `firstName` в дефолтные значения, форма может даже не начать валидацию этого поля, так как оно будет `undefined`.
